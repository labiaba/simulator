    Peluncuran
    Atur otomatis dari target jarak

    Tanpa kunci, program mencari tekanan paling rendah yang mencapai target, dengan sudut dan air di sekitar nilai efisien. Tekanan otomatis dibatasi 100 psi.

    –
    Nosecone dan pemberat

    Titik merah: CP (pusat tekanan). Lingkaran hitam-putih: CG saat berisi air. Lingkaran kosong: CG setelah air habis. CG harus di depan CP.

    Sirip
    Simpan desain saya

    Desain saya tersimpan di browser ini dan hanya bisa dilihat, dimuat, dan dihapus oleh Anda. Yang disimpan: semua parameter desain dan peluncuran, plus jarak prediksi, tinggi maksimum, dan margin stabilitas saat disimpan.

      Desain saya
        Parameter lanjutan

        Kalibrasi drag mengalikan koefisien drag hasil hitungan. Setelah uji lapangan, ubah sampai jarak simulasi cocok dengan jarak nyata.

        Asumsi model dan keselamatan
        • Botol 1,5 L: diameter 8,6 cm, panjang 31 cm, massa 42 g. Nosecone dimodelkan sebagai kerucut melengkung dari leher botol ke diameter penuh.
        • Udara mengembang adiabatik (γ = 1,4). Air keluar menurut Bernoulli (Cd nozzle 0,95). Sisa udara menyembur sebagai aliran tersedak atau subsonik.
        • Stabilitas memakai metode Barrowman (CP) dan dinamika rotasi 2D, jadi roket yang tidak stabil akan berputar dan jaraknya jatuh. Tanpa angin, tanpa parasut.
        • Hasil adalah perkiraan. Kalibrasi drag dengan data uji lapangan.
        • Tekanan 100 psi atau lebih berisiko memecahkan botol PET. Uji hidrostatik dulu, pakai pelindung mata, luncurkan dengan tali pelepas dari jauh, dan jangan mendekati roket yang sedang diberi tekanan.
        Menambah desain ke library
        1. Simpan desain di tab Library, lalu klik Ekspor sebagai library (designs.js).
        2. Ganti file library/designs.js di repo GitHub dengan file hasil ekspor, lalu commit.
        3. Setelah GitHub Pages memperbarui halaman, desain muncul di Library untuk semua pengunjung.

        Anda juga bisa menyunting library/designs.js langsung: setiap desain adalah satu objek di dalam array window.RA_LIBRARY.
